Memo MCP 개인정보처리방침

시행일: 2026년 11월 10일

Memo MCP는 개인용 Android 메모 앱입니다. 사용자가 Google Drive 동기화를 활성화하면 앱은 Google 계정의 Drive 접근 승인을 받아 사용자가 지정한 Memo MCP 폴더의 메모·첨부 파일을 휴대전화의 메모 폴더와 동기화합니다.

접근·사용하는 정보

앱은 Google Drive 전체 파일 접근 범위를 요청합니다. 이는 Drive 폴더 탐색과 선택한 폴더의 파일 생성·읽기·수정·삭제에 사용됩니다. 앱의 동기화 코드는 선택한 폴더 ID를 기준으로 작동합니다. 메모와 첨부 파일은 휴대전화와 해당 Google Drive 폴더에 저장됩니다.

ChatGPT 연결

사용자가 원격 연결을 켜면 ChatGPT의 MCP 요청에 따라 메모 또는 첨부 파일의 내용이 연결 서비스로 전달될 수 있습니다. 연결을 끄면 원격 요청을 받지 않습니다. Google Drive 데이터는 광고나 분석 목적으로 사용하지 않습니다.

인증 정보와 보관

Google 계정 승인은 Android의 Google Play 서비스를 통해 처리합니다. 앱은 한 번의 동기화에 사용할 접근 토큰만 메모리에서 사용하며 자체 저장소에 재인증 토큰을 보관하지 않습니다. 원격 연결용 키는 휴대전화의 Android Keystore로 보호해 저장합니다. 메모 본문과 인증값은 앱의 진단 로그에 기록하지 않습니다.

삭제와 권한 철회

사용자는 앱에서 로컬 메모를 삭제하고, Google Drive에서 동기화된 파일을 관리할 수 있습니다. Google 계정 설정에서 Memo MCP의 Drive 접근 승인을 언제든 취소할 수 있습니다. 앱을 삭제하면 앱 전용 설정과 원격 연결 키가 삭제됩니다. 휴대전화 공유 저장소와 Google Drive에 저장된 메모 파일은 별도로 삭제해야 합니다.

Memo MCP의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한된 사용 요건을 준수합니다.
