Memo MCP

Memo MCP는 Android 휴대전화에서 메모와 첨부 파일을 관리하고, 선택한 Google Drive 폴더와 동기화하는 개인용 앱입니다. 사용자가 연결 기능을 켜면 ChatGPT에서 MCP 도구로 메모를 읽고 작성할 수 있습니다.

Google Drive 사용

앱은 동기화에 필요한 Google Drive 접근 권한을 요청합니다. 실제 동기화 작업은 사용자가 앱에서 지정한 Memo MCP 폴더를 대상으로 수행합니다. 앱에서 Drive 폴더 연결을 해제하거나 Google 계정의 접근 권한 설정에서 승인을 취소할 수 있습니다.
